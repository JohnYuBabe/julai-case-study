# Provenance

- The three decisions and the nine-state matrix are derived from the author's
  own product design documents. No product source files were copied into this
  repository.
- All events, users and signups are synthetic. No customer data, no internal
  system names, and no code from any employer are included.
- Every number quoted in the ADRs comes from this repository's own test output;
  product-level metrics are intentionally not reproduced here.
